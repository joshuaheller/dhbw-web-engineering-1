# Bausteine

Die Code-Beispiele aus den Terminen. Jeder Ordner ist für sich lauffähig: `index.html` im Browser öffnen (oder Live Server starten), fertig. Wo npm nötig ist, steht es in der jeweiligen README.

Die Bausteine sind **keine Lösung für euer Projekt**. Sie zeigen ein Prinzip an einem kleinen Beispiel. Eure Aufgabe ist es, das Prinzip in eurem eigenen Projekt anzuwenden – mit euren Inhalten, eurer Struktur, euren Namen.

Jede README hier hat denselben Aufbau:

- **Worum es geht** – das Prinzip in zwei Sätzen
- **Starten** – wie ihr es zum Laufen bringt
- **Ins eigene Projekt** – welcher Teil übertragbar ist und welcher nicht
- **Änder mich** – zwei, drei Eingriffe, bei denen ihr vorher ratet, was passiert
