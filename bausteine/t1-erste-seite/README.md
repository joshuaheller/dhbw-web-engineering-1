# Eine Datei ist schon eine Webseite

## Worum es geht

Zehn Zeilen HTML, kein Framework, kein Server. Der Browser kann das direkt öffnen. Genau hier fängt alles an, was in diesem Kurs noch kommt.

## Starten

Doppelklick auf `index.html`. In der Adresszeile steht jetzt `file:///…` – kein Server beteiligt, die Seite existiert nur auf eurem Rechner.

## Ins eigene Projekt

Das ist der Startpunkt. Alles ab Termin 2 hängt an diesem Gerüst: `<!DOCTYPE html>`, `<html lang="de">`, `head` mit Infos über die Seite, `body` mit dem, was man sieht.

## Änder mich

1. Öffnet die DevTools (`F12`), Reiter **Elements**. Klickt die `<h1>` an und ändert den Text direkt im Browser. Ladet die Seite neu – was ist passiert, und warum?
2. Löscht die Zeile `<meta charset="utf-8">` und schreibt „Grüße aus Karlsruhe" in den Absatz. Was passiert mit dem ü? Ratet zuerst, dann testet.
3. Schreibt `<h1>` zweimal untereinander. Sieht gut aus? Wir reden in Termin 2 darüber, warum das trotzdem keine gute Idee ist.
